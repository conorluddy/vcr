# VCR

Agent-friendly studio for code-first motion graphics and video, shipped as a plugin for Claude Code and Codex. Read in this order:

1. `AGENTS.md` — working rules and write boundaries.
2. `specifications/vcr-prd.md` — product intent and release gates. `specifications/README.md` explains how it decomposes; `specifications/vcr-plugin-prd.md` covers the plugin and the review layer.
3. `catalog/TECHNIQUES.md` — one line per visual technique, when the look is still open (`pnpm vcr techniques info <id>`, then `--full`). `catalog/INDEX.md` — one line per tool; the entry point for choosing a tool. Then `pnpm vcr tools info <id>`, then `--full` for the guide, then `pnpm vcr tools examples <id>`. One tier at a time.
4. `specifications/decisions/` — ADR 0001 (engine in-house), 0002 (headless, no editor), 0003 (plugin, three roots), 0004 (disclosure and feedback), 0006 (creative pillars, independent of tools), 0007 (draft pillar agents) and 0010 (technique records join pillars to tools; status is derived) before proposing architecture. Also 0011 (inspiration library, separate from assets), 0012 (stated, measured and judged kept apart) and 0013 (models per agent, in the workspace). 0014 (look frames) is proposed, not yet accepted.
5. `specifications/roadmap.md` — what to build next, in order; loose ends live in the "Open work (living)" section of `AGENTS.md`. `references/README.md` — the creative pillars (typography, motion, pacing, delivery and the rest), their shared conventions and rule owners; start at `references/INDEX.md`, then `vcr rules info <ID>` or `vcr refs section <pillar> <§>`; never load a whole knowledge base.

Layer 0 is complete, the plugin is installable (plugin PRD P0, P1) and the review contract is in (P2: findings, render manifests, approvals, briefs, storage), beat sheets are checked before rendering (`vcr plan check`), and a workspace keeps the person's reference material in an inspiration library (`vcr inspiration`, the `inspiration` skill). The review pages (P3 onward) and Layer 1 have not started. Nothing in `catalog/` is installed unless `vcr doctor` says so, and nothing is validated unless its record carries evidence. After changing the CLI, catalogue, skills or examples, run `pnpm vcr plugin build`. `pnpm validate && pnpm test` before any PR.
