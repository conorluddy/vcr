# typed-ffmpeg

Python library that builds an FFmpeg filter graph as typed objects and compiles it to arguments for the system `ffmpeg`. It does not include FFmpeg.

`vcr` below means `node <plugin-root>/cli/vcr.mjs`; inside the VCR repository it is `pnpm vcr`.

## Use cases and limits
- Helps when a graph is generated by code, has many labelled pads, or is reused with parameters: you chain Python calls instead of hand-numbering `[s0][s1]` labels.
- Plain string filtergraphs (`-filter_complex "..."`) are simpler for one-off or short graphs. Encoding, muxing and probing advice lives in the `ffmpeg` skill; typed-ffmpeg only produces the command.
- Build-time checking covers stream kind only: an audio stream into a video input raises `FFMpegTypeError`. Wrong option VALUES are not rejected: `drawbox(width="abc")`, `testsrc(decimals="abc")`, `sine(sample_rate="abc")` and `overlay(eof_action="bogus")` all build and compile; ffmpeg fails later at render. Validate values yourself.
- Evidence covers macOS arm64, Python 3.12, FFmpeg 9.0.2 only. The TypeScript packages (documented as experimental) are untested.

## Capability map
- Tested: `ffmpeg.sources.testsrc` / `testsrc2` / `sine` (lavfi sources), `.scale`, `.overlay`, `.drawbox`, `.output(...)` with codec options and `extra_options`, `ffmpeg.compile.compile_cli.compile` (string) and `compile_as_list`, `FFMpegTypeError`.
- Untested: `hstack` and the rest of the filter set, audio graphs beyond the rejection case, other output options, running via the library itself, TypeScript packages, other FFmpeg versions or platforms.
- Entry points (discovery, not validation): [README](https://github.com/lucemia/typed-ffmpeg), [documentation](https://lucemia.github.io/typed-ffmpeg/), [FFmpeg filter reference](https://ffmpeg.org/ffmpeg-filters.html).

## Install and doctor
Use a virtualenv and the version-matched package for your FFmpeg; the meta-package `typed-ffmpeg` pulls the FFmpeg 9 binding `typed-ffmpeg-v9`:
```text
python3 -m venv output/venv
output/venv/bin/pip install typed-ffmpeg==4.6.2 typed-ffmpeg-v9==4.6.2 ffmpeg-core==4.6.2
ffmpeg -version | head -1      # 9.x expected for typed-ffmpeg-v9
vcr doctor                     # records ffmpeg; the Python package is not checked
```
Installation is not assumed. Validated 2026-11-24 on macOS arm64, Python 3.12.2, FFmpeg 9.0.2.

## Smoke test
```text
vcr example create typed-ffmpeg-graph && (cd examples/typed-ffmpeg-graph && ./run.sh)
# expect: typed-ffmpeg-graph: OK
```
`run.sh` creates its own venv under `output/`, compiles the graph in two processes (must be byte-identical), renders, and diffs ffprobe facts (h264, yuv420p, 320x180, 24/1, 48 frames, 2.000000 s).

## Build, compile, render
```python
from ffmpeg import sources
from ffmpeg.compile import compile_cli

base = sources.testsrc(size="320x180", rate="24", duration="2")
logo = sources.testsrc2(size="640x360", rate="24", duration="2").scale(w=160, h=90)
out = base.overlay(logo, x=10, y=10).drawbox(x=0, y=0, width=50, height=20, color="white", thickness="fill") \
    .output(filename="graph.mp4", vcodec="libx264", pix_fmt="yuv420p", r="24", t="2",
            extra_options={"movflags": "+faststart"})
args = compile_cli.compile_as_list(out)   # run: subprocess.run(["ffmpeg", "-y", *args])
```
- `compile` returns the command as one string; the fixture compares it with a predeclared string and it is stable across processes.
- `compile_as_list` omits `-y`; add it when overwriting.
- Compiled form: `-filter_complex 'testsrc=...[s0];...' -map '[s4]' -t 2 -r 24 -pix_fmt yuv420p -vcodec libx264 ...`. Output options are emitted in the library's order, not the order you wrote.

## Stream-kind check
```python
tone = sources.sine(frequency=440, sample_rate=48000, duration="2")
video.overlay(tone)   # FFMpegTypeError: Expected input 1 to have video component, got AudioStream
```
Raised at construction, before any ffmpeg call.

## Troubleshooting
- Graph builds but ffmpeg errors at render: an option value is wrong (not checked at build). Read ffmpeg's stderr and compare with the filter reference.
- Import or compile differences after upgrading: pin all three packages; revisit the expected command if `compile_as_list` output changes.
- Wrong binding for your FFmpeg: use the `typed-ffmpeg-v<N>` package matching the major version.
