# VCR CLI reference

Generated by `vcr plugin build` from `packages/cli/src/commands.ts`. Do not edit; `vcr validate` fails when it is stale. Every command also answers `--help`.

## Global flags

| Flag | Description | Default |
| --- | --- | --- |
| `--json` | Machine-readable output; errors become { error: { code, message, retryable } } |  |
| `--workspace dir` | Select a workspace instead of discovering one from the current directory |  |
| `--help` | Print help for the command (also -h) and exit 0 |  |

## Environment

- `VCR_HARNESS`: Harness root (the repository or the installed plugin)
- `VCR_WORKSPACE`: Workspace root; overrides discovery
- `VCR_HOME`: Machine state: runtime, environment records (default ~/.vcr)

## `vcr status [--brief]`

Show the harness, workspace and machine roots; --brief for videos awaiting review and open findings (under 1 KB)

| Flag | Description | Default |
| --- | --- | --- |
| `--brief` | Videos needing attention first, with open-finding counts and warnings |  |

```sh

```

## `vcr findings add <project>/<video> --frame n --severity level --text text [--render id] [--frame-end n] [--rule ID] [--selector css] [--author kind]`

Add a note on a render frame; scene and scene frame come from the manifest; idempotent on content

| Flag | Description | Default |
| --- | --- | --- |
| `--frame n` (required) | Composition frame |  |
| `--severity level` (required) | blocker, major, minor or note |  |
| `--text text` (required) | One issue, in a sentence |  |
| `--render id` | Retained render | `the latest` |
| `--frame-end n` | Last frame of a range, inclusive |  |
| `--rule ID` | Pillar rule, e.g. TYPO-SAFE |  |
| `--selector css` | Where in the scene DOM |  |
| `--author kind` | agent or human | `agent` |

```sh
vcr findings add demo/teaser --frame 45 --severity major --text "Headline crosses the safe zone" --rule TYPO-SAFE
```

| --- | --- | --- |

## `vcr storage clear <output|cache|proxies|runtime> [--video project/video] [--render id] [--older-than days] [--keep-latest n] [--yes]`

Plan the deletion of regenerable files and print it; --yes applies. Never touches projects, review/ or briefs

| Flag | Description | Default |
| --- | --- | --- |

| `--yes` | Apply the plan instead of printing it |  |

```sh

```

## `vcr capture <scene.html> --width n --height n --fps n [--out dir] [--video project/video] [--verify]`

Capture a browser scene frame by frame; frames and report.json go to --out, or with --video become a render with a manifest

| Flag | Description | Default |
| --- | --- | --- |
| `--width n` (required) | Viewport width in pixels |  |
| `--height n` (required) | Viewport height in pixels |  |
| `--fps n` (required) | Frames per second |  |
| `--out dir` | Output directory; not with --video | `<scene dir>/output` |
| `--video project/video` | Record a render of this video: frames under output/<video>/<render_id>/, the manifest there and in review/renders/<render_id>/ |  |
| `--verify` | Recapture in shuffled order and compare; exit 1 if frames differ |  |

- `VCR_CAPTURE_MODE`: Frame grab method: screenshot (default) or beginframe

```sh
vcr capture scene.html --width 1920 --height 1080 --fps 30 --verify
```

## `vcr lint <scene.html|dir> --safe-zone preset [--at t1,t2] [--markers] [--samples n] [--width n] [--height n] [--fps n] [--video project/video] [--render id]`

Check a browser scene's text against a safe zone, the frame edges and overflowing boxes at sampled times; exit 1 on findings

| Flag | Description | Default |
| --- | --- | --- |
| `--safe-zone preset` (required) | ebu-16x9, tiktok, reels, shorts, composite-9x16 (references/typography/rules.json), or none |  |
| `--at t1,t2` | Sample at these times in seconds |  |
| `--markers` | Sample at window.__scene.markers (seconds or { t, id, role }), e.g. just before each beat ends |  |
| `--samples n` | Evenly spaced samples from 0 to the last frame | `8` |
| `--width n` | Viewport width in pixels; required with --safe-zone none | `the preset's canvas` |
| `--height n` | Viewport height in pixels; required with --safe-zone none | `the preset's canvas` |
| `--fps n` | Frames per second, for frame numbers and the last sample | `30, or the render's with --video` |
| `--video project/video` | File each finding on a retained render of this video (idempotent; re-running adds nothing new) |  |
| `--render id` | With --video: the render the findings point at | `the latest` |

```sh
vcr lint scene.html --safe-zone tiktok --markers --video demo/teaser
```
