## Intent and scope

- Tool ID and version/build: `gltfjsx` 6.5.3 (npm, MIT), installed project-local and exact-pinned in this example's `package.json`; not run through `pnpm dlx`.
- VCR job and exact claim being tested: `gltfjsx --types --keepnames` converts a generated two-material GLB with named nodes into a TSX component that references the predeclared node and material names, and two conversions of the same GLB are byte-identical.
- Narrowed claim, decided before running: the brief's strict-typecheck and r3f-render claims are not exercised here. The generated component imports `useGLTF` from `@react-three/drei` and the `GLTF` type from `three-stdlib` (both emitted by gltfjsx 6.5.3's template, `src/utils/parser.js`). Neither package is pre-approved for this example, so neither is installed. Typecheck and render are recorded as `not-run`, not passed.
- Explicit exclusions: strict typecheck of the component; rendering in the r3f capture route; any runtime loading of the GLB; `--transform`, Draco and meshopt; animations, instancing, skinning, cameras and lights; gltfjsx options other than `--types` and `--keepnames`; semantic fidelity of the generated JSX beyond the name and count checks; gltf-transform and other catalogue tools (not used).
- Tool documentation and licence sources: https://github.com/pmndrs/gltfjsx (the card's official URL; not re-read in this run) and https://www.npmjs.com/package/gltfjsx. Licence MIT per npm registry metadata, read 2026-11-24. The gltfjsx 6.5.3 tarball was unpacked into a scratch directory and its template read (`src/utils/parser.js`); it was not executed. Generated code carries no separate licence.
- Environment: macOS Darwin 25.6.0 arm64, Node.js and pnpm as installed on the executing machine (recorded in the observation).
- Input: generated by `make-input.py` (Python standard library only). One GLB 2.0 file, no external assets: group `CrateGroup` with children `Body` (single triangle, material `Wood`) and `Clasp` (single triangle, material `Metal`, translated 0.5 up). Two materials, `Wood` and `Metal`, with fixed PBR factors. Rights: generated by this fixture; no third-party content.
- Dependencies, installation plan, permissions, network and expected side effects: one install, `gltfjsx@6.5.3` as a devDependency of this example, via `pnpm install` in the example. No browser.
