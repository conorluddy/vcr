# Matter.js rigid-body capture

## Intent and scope
Matter.js 0.20.0 (npm, last release 2024-06-23); 2D rigid-body physics stepped by re-simulation. `seek(t)` rebuilds the world from the same initial state and calls `Matter.Engine.update` with a fixed 1000/60 ms step `floor(t*60)` times, then draws body vertices with plain Canvas 2D. Matter.Render and Matter.Runner are not used, because they own a clock. Claim: rigid bodies seeked by re-simulation give 90 alpha frames at 1280×720, 30 fps, and shuffled capture equals sequential. Excludes Matter.Render, Runner, sleeping and collision-event behaviour, cross-machine byte equality, and other browsers. Procedural original shapes only; no media or fonts. Code MIT, checked 2026-11-11: https://brm.io/matter-js/ ; licence https://raw.githubusercontent.com/liabru/matter-js/master/LICENSE . No codec, model or asset dependency.

## Plan, before running
On macOS arm64, install pinned matter-js 0.20.0 in this pnpm workspace (pre-approved package), reuse Playwright 1.64.1 and tsx 4.23.15. Run `pnpm install`, then `examples/matterjs-capture/run.sh --record`, visually inspect frames at native 1280×720, then `examples/matterjs-capture/run.sh`. Browser build is `node_modules/matter-js/build/matter.min.js`, loaded by a relative script tag. Record the exact browser version from the capture report. No system-wide changes.

Predeclared checks: 90 frames at 30 fps, 1280×720, at least two distinct frame hashes, every shuffled hash equal to sequential, frame 45 alpha minimum 0 and maximum 1. Assert these before recording expected/summary.json. Stop on missing dependencies, blank output, or any mismatch. Visual check: boxes and circles visibly lower across frames and come to rest on the ground. Intended consumer is the existing browser capture harness; units are seconds and pixels. Transparent PNG sequence only; no delivery byte budget claim. Outputs and reports in ignored output/; delete that directory to clean up.

## Observation, after running
2026-11-11, evidence agent on Conors-MacBook-Pro-2.local, macOS Darwin 25.6.0 arm64, Node 22.19.0, matter-js 0.20.0, Playwright 1.64.1, Chromium 156.0.8078.4, ImageMagick 7.1.2-15. Screenshot capture route, Canvas 2D backend. GPU details unknown and not claimed.

`run.sh --record` and a second `run.sh` both exited 0; the second printed `matterjs-capture: OK`. Each run produced 90 distinct frame hashes; sequential and shuffled matched on all frames (`shuffled_matches_sequential: true`). Frame 45 alpha was 0 to 1. Capture took about 4.6 s wall time. Visually inspected a contact sheet of frames 0, 15, 30, 45, 60 and 89 at native 1280×720 (`output/contact.png`): the four boxes and four circles fall from the top, tumble, land on the static ground and settle, with a visible change between frames and a transparent background. Agent visual review only; no human approval claimed. Result: pass for the stated claim. Not Matter.Render or Runner, not collision events or sleeping, not cross-platform byte equality. Revalidate on matter-js or Playwright changes.
