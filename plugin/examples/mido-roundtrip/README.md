# Mido Standard MIDI File round trip

## Intent and scope

- Tool ID and version/build: `mido` 1.3.2.
- VCR job and exact claim: write a small owned type-1 Standard MIDI File, reopen it with Mido, and save it again while preserving declared track/event semantics.
- Explicit exclusions: MIDI 2.0, SysEx, running status edge cases, live ports/backends, synthesis, playback, and musical quality.
- Tool documentation and licence: [Mido stable MIDI file documentation](https://mido.readthedocs.io/en/stable/files/midi.html), [Mido API](https://mido.readthedocs.io/en/stable/api.html); MIT. Checked 2026-11-15.
- Environment: macOS 26.6 arm64, Python 3.9.6.
- Input: generated by `make_fixture.py`, using only original tempo and note event values; no external MIDI content.
- Dependencies and install plan: `python3 -m venv output/venv`, then install pinned `mido==1.3.2` from PyPI into that ignored fixture-local environment. Network required on first run; no global Python packages or audio backend are changed.
- Output and cleanup: `output/` is ignored; generated MIDI files and the virtual environment stay there.

## Plan, before running

- Exact command: `./run.sh --record`, then `./run.sh`; both invoke Python scripts using the fixture virtual environment and Mido 1.3.2.
- Checks: file header type 1, 480 ticks per beat, two tracks, one 500000 µs/beat tempo event, note-on at delta 0 and note-off at delta 480 for note 60/velocity 72, and byte-identical first and second saves.
- Expected artifacts: `output/source.mid`, `output/roundtrip.mid`, and `expected/metrics.json`.
- Stop if the installed package version differs from 1.3.2, MIDI header or event assertions fail, or two serial saves differ.
- Inspection: inspect the generated JSON metrics and MIDI event list; no audio is produced by this claim.

## Observation, after running

- Executor/date: Codex, 2026-11-15; `Conors-MacBook-Pro-2.local`, macOS 26.6 arm64, Python 3.9.6.
- Observed: Mido 1.3.2 read and rewrote a 54-byte type-1 MIDI file (480 ticks/beat, two tracks, 500000 µs/beat tempo, two note events, note-off delta 480); repeated saves were byte-identical, SHA-256 `dfde7981717f295a00b1959fe1010fd5d0b37f6063e3022e4ec23324f33ac5b9`.
- Inspection: parsed event values and retained metrics were inspected; this fixture makes no audio and requires no MIDI device.
- Pass: `./examples/mido-roundtrip/run.sh --record` recorded expected metrics; a second `./examples/mido-roundtrip/run.sh` printed `OK mido-roundtrip`.
- Limitations/deviations: no playback, port/backend, synthesis, other MIDI formats, or cross-platform claim. Pip emitted a cache-permission warning and disabled its cache; the fixture-local install and run succeeded.
