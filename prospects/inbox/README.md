# Prospects inbox

Weekly discovery digests from the scheduled routine ([../DISCOVERY-ROUTINE.md](../DISCOVERY-ROUTINE.md)). Each entry is an unassessed lead, not a catalogue record: nothing here is catalogued, installed or validated.

- One file per run: `YYYY-MM-DD-discovery.md` (Europe/Dublin date), added by a `discovery/<YYYY-Www>` PR.
- Triage each lead by ticking `assess`, `defer` or `retire`.
- Promotion follows [catalog/CANDIDATE-INGESTION.md](../../catalog/CANDIDATE-INGESTION.md): a maintainer writes the `candidate` record in `catalog/tools/`.
- Past digests are append-only history; edit them only to tick triage boxes. The routine dedupes against them.
