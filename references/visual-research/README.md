## Integration notes and open decisions

- **Tier and evaluation method differ.** The supplied table used `structural` and `advisory` as tiers. Those labels now live in evaluation methods. Candidate rules are `heuristic`: source standards inform locator notation but do not mandate VCR board workflows. Their verification remains separate.
- **Evidence limits.** Several sources were inspected only through abstracts, excerpts or secondary accounts. The ledger records this unevenly as confirmed or unverified. Import does not independently verify either label. Fixation findings largely concern short design tasks; application to image and video production is an extrapolation.
- **Ownership.** [Domain exploration](../domain-exploration/README.md) owns generic source evaluation and subject understanding. This reference owns reading visual examples, comparison, influence and transferable principles. [Cultural context](../cultural-context/README.md) owns audience meanings. Story owns routes; Art Direction owns the chosen treatment. [Image direction](../image-direction/README.md) owns image briefs, asset selection and set coherence.
- **Before distillation.** Reconcile shared source, locator, date, storage and provenance rules with Domain. Keep this as a separate reference for now because its analysis, fixation and transfer methods have a distinct purpose; revisit the split against actual use.
- **Boundary.** Boards and templates live in production workspaces. No reference-search service, board schema, originality metric or reuse permission is implied. Judged findings remain advisory under `REVIEW-*`.
