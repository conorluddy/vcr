# Production field notes

Original reports from real use of VCR. These are dated evidence records, not harness instructions, accepted designs or statements of current capabilities. Preserve observed behaviour separately from interpretation and proposals; corrections should identify what changed and when.

Name reports `YYYY-MM-DD-short-topic.md`. Record the environment, plugin version and source commit when known, reproduction/evidence, workarounds and limitations. Link the running field-note issue and focused follow-ups. Keep generated media in ignored output directories or the production workspace, never here.

Keep reports domain-agnostic by default. The initial user-supplied report is retained here at the owner's explicit request with its production context. Review private paths, names and rights before public release; cross-repository local evidence links are not portable and do not grant access to the underlying files.
