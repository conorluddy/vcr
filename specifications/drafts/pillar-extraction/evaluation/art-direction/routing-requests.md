# Routing requests

Classify each independently and explain the choice briefly.

1. “We need a visual language for a series of short explainers. Develop a palette, shape system and focal hierarchy from the brief.”
2. “This static frame feels crowded. Adjust its composition so the primary idea reads first while retaining the established visual language.”
3. “The composition is approved. Design how the focal element moves between these two positions and specify the movement character.”
4. “Choose imagery for the approved visual direction, documenting suitability, provenance and placement constraints.”
5. “Check whether the encoded file meets its delivery specification and report the evidence.”
6. “Write a script that makes the central argument clear in three beats.”
