# Art direction pilot evaluation

These reusable, fictional cases evaluate the unpublished draft, not a calibrated skill or production result. Give an independent evaluator the draft and one request at a time; do not provide `expected.md` until after the response is recorded. For task cases, provide the files explicitly named in the request and a writable scratch copy if editing is requested. Preserve the raw response and any changed artifacts outside this directory; do not overwrite the fixtures. Compare the response with the expected observable outcomes, recording partial results, unsupported claims, uncertainty and context used. No numerical score or passing threshold is prescribed.

Use [routing requests](routing-requests.md) independently: decide whether art direction is the primary workflow, a related handoff, or unrelated, with a brief reason. [Routing expectations](routing-expected.md) are evaluator-only. The [creation request](tasks/creation/request.md) and [local revision request](tasks/local-revision/request.md) each have a separate evaluator-only `expected.md`. The latter includes a static SVG, not a render sequence or delivery file.
