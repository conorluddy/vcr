# Skill authoring contract

Add a toolkit guide only when its workflow has an example and honest operational evidence. An operational toolkit guide should cover:

- use cases and limitations
- installation and supported versions
- doctor checks and a smoke test with expected output
- a native API example and clock/seeking rules
- asset loading, capture/export, and cleanup
- troubleshooting and official documentation links

Workflow guides should stay separate from toolkit setup. Load only the guide needed for the current production task.
