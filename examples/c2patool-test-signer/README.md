# c2patool development-signer PNG manifest

## Intent and scope

- Tool ID and version/build: c2patool 0.29.0, Homebrew stable bottle installed on 2026-11-16.
- VCR job and exact claim being tested: add a C2PA manifest to an owned PNG with c2patool's built-in development signer, then read the manifest with c2patool and assert the declared title, claim generator info, and custom assertion data.
- Explicit exclusions: trusted signer identity, provenance truth/completeness, production key handling, timestamps, other media formats, and other operating systems.
- Documentation: https://github.com/contentauth/c2patool/blob/main/docs/usage.md, https://github.com/contentauth/c2patool/blob/main/docs/manifest.md, and https://github.com/contentauth/c2patool/blob/main/docs/signing.md (checked 2026-11-16); project license Apache-2.0 OR MIT.
- Environment: macOS 26.6 arm64; exact c2patool/OpenSSL versions and host recorded after execution.
- Input: deterministic 64x48 RGB PNG generated by make_fixture.py, no third-party asset.
- Dependency/install plan: brew install c2patool installed 0.29.0. User authorized installation. c2patool's built-in development key/certificate are used; no private key or certificate is generated or committed.
- Generated PNGs, manifest JSON, signing/readback reports stay in ignored output/; only metrics JSON is retained.

## Plan, before running

- Exact commands: ./examples/c2patool-test-signer/run.sh --record, then ./examples/c2patool-test-signer/run.sh twice.
- Recipe: Python standard library generates one deterministic RGB PNG. c2patool embeds a manifest with title VCR c2patool fixture, claim generator info VCRFixture 1.0, and custom label org.contentauth.test using its documented built-in development signer; no timestamp authority is configured.
- Checks: exact tool version 0.29.0; c2patool signs the generated PNG and reads the signed PNG as JSON; assert one active manifest, expected title and claim generator info, exact custom assertion payload, cryptographic signature validation success, and explicit untrusted test signer status; assert source PNG dimensions and SHA-256. Do not assert signer trust, provenance authenticity, or signed-file byte repeatability.

This is development-only signing evidence, not a real identity or provenance claim.
