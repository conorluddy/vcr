# regl capture

## Intent and scope
regl 2.1.1 (functional WebGL, draw commands declared as functions of props); pure-time uniforms on a WebGL canvas, alpha PNG capture. Claim: regl draw commands (a fragment-shader gradient quad, then twelve triangles in one draw) take a `time` uniform from `t`; each seek performs `regl.clear` plus command calls once, with no `regl.frame()`; the canvas uses `preserveDrawingBuffer: true` and `premultipliedAlpha: true` (WebGL default), so output is premultiplied; 90 alpha frames at 1280×720, 30 fps; shuffled capture equals sequential.
Exclusions: regl's `profile` option and `regl.now()` (both read `performance.now`, see below), `regl.frame()` loops, instanced drawing (see Observation), WebGL2-only features, context loss, other browsers, GPUs and drivers beyond this machine, interaction, and any cross-machine pixel equality. Procedural original shapes only; no media or fonts. No bundler; the library is loaded from `node_modules/regl/dist/regl.min.js` via a relative script tag.

Unseeded clock check, grep of `node_modules/regl/dist/regl.js` for `Math.random`, `performance.now` and `Date.now`: no `Math.random`. `performance.now` is read in `clock()` (sets the start time at creation and backs `regl.now()`), and in the `profile` codegen path (only when `profile: true`). `Date.now` appears only as the fallback inside that profile codegen when `performance` is undefined. This fixture calls neither `regl.now()` nor `profile`, so no clock value reaches a pixel. Excluded: `regl.now()` and `profile: true` are out of the claim.

Licence and docs: regl is MIT (`node_modules/regl/package.json` at 2.1.1, checked 2026-11-11); docs https://github.com/regl-project/regl and the tool card (`pnpm vcr tools info regl`). No codec, model or asset dependency.

## Plan, before running
On macOS arm64, install pinned regl 2.1.1 locally in this pnpm workspace (pre-approved package); reuse Playwright 1.64.1 and tsx 4.23.15 as in konva-capture. Run `pnpm install`, then `examples/regl-capture/run.sh --record`, visually inspect frames at 1280×720, then `examples/regl-capture/run.sh`. Record the exact browser version from the capture report and the log, not from the plan.

Predeclared checks: 90 frames at 30 fps, 1280×720, at least two distinct frame hashes, every shuffled hash equal to sequential, frame 45 alpha minimum 0 and maximum 1 (transparent background, opaque triangles). Assert these before recording `expected/summary.json`. Stop on missing dependencies, blank or clipped output, or any mismatch. Shuffled order uses the capture harness's fixed seed. Intended consumer is the existing browser capture harness; units are seconds and pixels. Transparent PNG sequence only; no delivery byte budget or compression claim. Outputs and reports stay in ignored `output/`; delete that directory to clean up. No cross-machine byte equality asserted.

## Observation, after running
2026-11-11, evidence agent on Conors-MacBook-Pro-2.local, macOS Darwin 25.6.0 arm64, Node 22.19.0, regl 2.1.1, Playwright 1.64.1, Chromium 156.0.8078.4 (WebGL 1.0, OpenGL ES 2.0 Chromium backend; reported by `getParameter(VERSION)`), tsx 4.23.15, ImageMagick 7.1.2-15. Screenshot capture route (`captureMode: screenshot`). Context attributes read back: alpha true, premultipliedAlpha true, preserveDrawingBuffer true, antialias false. GPU and driver details not claimed.

Deviation: the first draft drew the twelve triangles with `instances` and an `instanceIndex` attribute. The first `--record` run wrote 90 frames with matching shuffled hashes, but frame 45 alpha max was 0.851 (the quad's ceiling), so the triangles were absent and the check failed. The run was not recorded. A probe showed the triangles missing with no GL error. Two changes followed: triangles became one 36-vertex non-instanced draw, and both commands disable the depth test. The gradient quad writes depth 0 and the triangles at depth 0 failed regl's default LESS test, which hid them. The exact cause of the instanced failure was not isolated, so instancing is not claimed. The predeclared checks and thresholds were not changed.

Run results: `run.sh --record` exited 0 after the change, then `run.sh` printed `regl-capture: OK` (the template's hard-coded `konva-capture` label was corrected in run.sh before this run). Capture report: 90 frames, 1280×720, 30 fps, 90 distinct SHA hashes, shuffled order matched sequential for all 90 frames (no mismatched frames), wall time 12.7 s, 7.1 fps in screenshot mode. Frame 45 alpha min 0, max 1. `expected/summary.json` retains these measurements; hashes stay in the ignored `output/report.json`.

Visual inspection: `output/contact.png` (frames 0, 15, 30, 45, 60, 75, 3×2 montage, rendered over grey to show alpha). The frames show a blue-to-orange gradient band whose colour and radial falloff move with `time`, a translucent edge that fades to transparent at the corners, and twelve opaque coloured triangles on a circular orbit that rotates over time. Nothing is blank or clipped. Defects seen: 8-bit banding in the gradient, and faint vertical streaking near the wave edge in some frames (visible around the left and right gradient edges at frames 15 and 30). Both come from the `mediump` gradient shader and do not affect the claim. Agent visual review only; no human approval claimed.

Result: pass for the stated claim: a regl gradient plus triangle draw, driven from `t` on one seek-per-frame, is captured deterministically with premultiplied alpha. Not established: instancing, `regl.frame()` loops, `regl.now()` or profiling, other browsers, GPUs, WebGL2, quality beyond the visual inspection above. Revalidate on regl, Playwright or Chromium changes.
