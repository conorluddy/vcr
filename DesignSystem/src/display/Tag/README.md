# Tag

Mono caps status tag.

```jsx
<Tag variant="solid">FIXED</Tag>
<Tag>REFERENCE</Tag>
<Tag variant="muted">DRAFT</Tag>
```

- `outline` (bone hairline) for final states and REFERENCE imagery; `muted` (`vcr-line-hover`, `vcr-text-tertiary`) for DRAFT; `solid` (bone fill) for FIXED inputs, A/B labels and file types.
- A fixed asset appears in every design unaltered, so it gets the solid tag; reference imagery only guides the look.
- 8px mono at `vcr-tracking-tag`. Write the text in caps.
