# GroupHeader

Caps group header with a hairline and an optional section code, at the top of a group inside a tray or popover.

```jsx
<GroupHeader title="Typography appearance" code="CONT.02" />;
```

- `title` is set in mono at `vcr-tracking-heading`, `vcr-text-strong`; `code` in `vcr-text-quiet`.
- Carries a 12px bottom margin; the group's controls follow directly.
