# Readout

Label-over-value readout cell in tabular mono, for facts the machine reports.

```jsx
<Readout label="SIZE" value="1080 × 1350 PX" />;
```

- Label in `vcr-text-quiet` at `vcr-font-size-micro`, tracked; value in `vcr-bone`, tabular figures.
- Write units in caps (PX) and an empty value as "—".
